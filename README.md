# Multi Tabs for Odoo 16 - 独立实现版本

这是一个为 Odoo 16 设计的多标签页应用，通过完全独立的实现方式提供类似浏览器的多标签页功能。

## ✨ 功能特性

- **自动标签页管理**：访问新页面时自动创建标签页
- **智能标题识别**：从面包屑、页面元素中自动提取有意义的标题
- **完整的标签页操作**：
  - 点击标签页切换到对应页面
  - 关闭单个标签页（点击 ✕）
  - 关闭其他标签页（点击 ⊟）
  - 关闭所有标签页（点击 ✕✕）
- **智能显示**：只有存在多个标签页时才显示标签栏
- **美观界面**：现代化的标签页设计，支持响应式布局

## 🚀 安装方法

1. 将此模块放置在您的 Odoo 16 addons 目录中
2. 重启 Odoo 服务器
3. 在应用管理中搜索 "Multi Tabs"
4. 点击安装
5. 刷新浏览器页面

## 📖 使用方法

安装后，多标签页功能将自动启用：

1. **创建标签页**：点击不同的菜单项会自动创建新的标签页
2. **切换标签页**：点击标签页标题切换到对应页面
3. **关闭标签页**：
   - 点击标签页上的 ✕ 关闭单个标签页
   - 点击右侧的 ⊟ 关闭其他标签页
   - 点击右侧的 ✕✕ 关闭所有标签页

## 🛡️ 技术特点

### 独立实现架构
- **无核心修改**：不修改 Odoo 的 ActionContainer 等核心组件
- **完全安全**：避免与其他模块冲突，不会导致白屏等问题
- **高度兼容**：适用于各种 Odoo 16 环境（社区版/企业版）

### 实现原理
- **URL 监控**：通过监听 URL 变化自动管理标签页
- **DOM 操作**：使用纯 JavaScript DOM 操作创建标签页界面
- **延迟加载**：延迟启动避免与 Odoo 初始化冲突
- **错误处理**：完善的异常捕获和处理机制

## 💻 技术细节

### 核心文件
- `akl_action_container.js`：主要的标签页管理逻辑
- `simple_tabbar_css.scss`：标签页样式文件
- `__manifest__.py`：模块配置文件

### 关键类
- `SafeTabManager`：核心标签页管理器
  - 负责标签页的创建、切换、关闭
  - URL 监控和页面标题提取
  - DOM 操作和事件处理

## 🔧 自定义配置

### 修改标签页样式
编辑 `simple_tabbar_css.scss` 文件来自定义：
- 标签页位置和大小
- 颜色和字体
- 响应式断点

### 调整功能行为
在 `akl_action_container.js` 中可以修改：
- URL 监控频率（默认1秒）
- 延迟启动时间（默认2秒）
- 标题提取规则

## 🐛 故障排除

### 常见问题
1. **标签页不显示**：检查控制台是否有错误，确认模块正确安装
2. **标题显示不正确**：检查页面元素，可能需要调整标题提取规则
3. **样式问题**：清除浏览器缓存，强制刷新页面

### 调试模式
在浏览器控制台中查看日志：
- "Tabbar module loaded - adding tab functionality"
- "Tab container created"
- "URL monitoring started"
- "Safe tab manager started successfully"
